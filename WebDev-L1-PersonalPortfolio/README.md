
# Owais – Personal Portfolio Website 🚀

A modern, responsive personal portfolio website developed using HTML5 and CSS3 to showcase my profile, technical skills, projects, and contact information.

This project is developed as part of the **Oasis Infobyte Web Development Internship – Level 1, Task 2 (Personal Portfolio)**.

---

## 🌐 Project Overview

The Personal Portfolio Website serves as my digital résumé, providing an overview of my educational background, technical expertise, development projects, and professional interests.

It features a modern dark-themed interface, clean typography, responsive layouts, and smooth navigation to provide visitors with a professional browsing experience.

## ✨ Features

- **Hero Section:** Displays my name, professional role, introduction, and profile photo/avatar.
- **About Me:** Introduces my educational background and professional interests.
- **Technical Skills:** Showcases programming languages, frameworks, and development tools.
- **Projects Section:** Highlights my projects with descriptions and GitHub links.
- **Contact Section:** Provides email, GitHub, and LinkedIn information.
- **Fixed Navigation Bar:** Keeps navigation links accessible while scrolling.
- **Smooth Scrolling:** Enables smooth navigation between website sections.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Modern UI:** Professional colour palette, gradients, and hover effects.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Website structure |
| CSS3 | Styling and visual design |
| CSS Flexbox | Flexible layouts |
| CSS Grid | Responsive section layouts |
| CSS Media Queries | Mobile responsiveness |
| Google Fonts | Typography |

**Note:** This project is developed using HTML5 and CSS3. JavaScript is not required.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Owaisraza005/OIBSIP.git
```

### 2. Navigate to the Portfolio Folder

```bash
cd OIBSIP/WebDev-L1-Portfolio
```

### 3. Open in VS Code

```bash
code .
```

### 4. Run the Website

Open `index.html` directly in your browser.

Alternatively, use the Live Server extension in Visual Studio Code:

1. Right-click on `index.html`.
2. Select **Open with Live Server**.
3. View your portfolio in the browser.
