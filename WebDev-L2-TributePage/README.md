# Dr. A. P. J. Abdul Kalam Tribute Page

A responsive and visually engaging tribute page dedicated to **Dr. A. P. J. Abdul Kalam**, one of India's most respected scientists, educators and public figures.

This project was created as part of the **Oasis Infobyte Web Development and Designing Internship – Level 2, Task 2**.

## Project Overview

The purpose of this project is to create a dedicated tribute webpage for an inspirational public figure using HTML5 and CSS3.

The page presents Dr. A. P. J. Abdul Kalam's life, scientific journey, achievements, presidency and lasting influence on students and young people.

## Features

- Hero section with Dr. A. P. J. Abdul Kalam's name and tagline
- Prominent portrait image
- Four-paragraph biography section
- Milestones and achievements timeline
- Distinctive quote sections
- Multiple background colors
- Serif and sans-serif typography
- Responsive design for desktop, tablet and mobile devices
- Smooth scrolling
- Hover effects and interactive visual elements
- Clean and modern editorial-style layout

## Technologies Used

- **HTML5** – Page structure and semantic elements
- **CSS3** – Styling, layout, animations and responsive design
- **Google Fonts** – Playfair Display and Poppins
- **Wikimedia Commons** – Tribute image source

## Sections Included

### 1. Hero Section

Introduces Dr. A. P. J. Abdul Kalam with:

- His name
- A short tagline
- A prominent portrait
- Navigation button to the tribute section

### 2. Biography

The biography section describes important stages of his life, including:

- Early life and education
- Aerospace engineering
- Scientific career
- Space and defence programmes
- Presidency of India
- Work with students and education

The content has been written in original wording and is intended as a paraphrased summary rather than copied source material.

### 3. Milestones & Achievements

A visual timeline presents important events from his life, including:

- 1931 – Birth
- 1954 – Physics education
- 1955 – Aerospace engineering
- 1980 – SLV-III success
- 1998 – Pokhran-II
- 2002 – President of India
- 2015 – Final lecture

### 4. Quote Section

The page contains prominently styled quotations associated with Dr. Kalam to reflect his philosophy of dreams, education and action.

### 5. Legacy

The final content section highlights his influence on:

- Students
- Education
- Science
- National development
- Young people

## Design

The webpage uses a combination of two major typefaces:

- **Playfair Display** – Headings and quotations
- **Poppins** – Body text and interface elements

The page also uses multiple visual backgrounds, including:

- Dark navy
- Cream
- Gold

This creates visual separation between different sections of the page.

## Responsive Design

The website is designed to work across different screen sizes.

Responsive CSS media queries adjust:

- Hero layout
- Image size
- Typography
- Timeline structure
- Section spacing
- Quote size
- Mobile layout

The desktop layout uses a two-column hero section, while smaller screens automatically switch to a single-column layout.

## How to Run

No server or installation is required.

1. Download or clone the repository.
2. Open the `WebDev-L2-TributePage` folder.
3. Make sure the `images` folder contains `apj-abdul-kalam.jpg`.
4. Open `index.html` in a web browser.

You can also use the **Live Server** extension in Visual Studio Code for development.

## Testing

The webpage should be tested on:

- Desktop browsers
- Tablet screens
- Mobile devices

Check the following:

- Hero image loads correctly
- All sections are visible
- Typography displays correctly
- Timeline remains readable
- Responsive layout works on smaller screens
- Button scrolls to the tribute section
- No horizontal scrolling occurs on mobile
