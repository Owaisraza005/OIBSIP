# CalcPro – Calculator

A responsive browser-based calculator developed as part of the Oasis Infobyte Web Development and Designing Internship – Level 2, Task 1.

## Features

- Addition, subtraction, multiplication and division
- Decimal number calculations
- Operator chaining with mathematical precedence
- Clear and delete functionality
- Division-by-zero error handling
- Keyboard support
- Responsive design
- CSS Grid button layout
- Custom calculation logic without using `eval()`

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start using the calculator.
